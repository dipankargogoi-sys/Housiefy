To sync rooms across everyone's phones this app needs a free database. One-time setup:

1. Go to console.firebase.google.com → Create project (any name).
2. In the project, open Build → Realtime Database → Create database → start in test mode.
3. Click the gear icon → Project settings → under "Your apps" click the </> (web) icon → register app.
4. Copy the whole firebaseConfig object shown and paste it below.
